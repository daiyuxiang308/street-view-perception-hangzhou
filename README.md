# 杭州市街景主观感知预测与空间冷热点分析

## 1. 项目简介

本项目围绕杭州市主城区街景图像，开展街景主观感知预测与空间冷热点分析。

研究首先利用专家训练后的大语言模型，对 2000 份街景图像进行六个维度的主观感知评分，包括安全、活力、富裕、美丽、无聊和压抑。评分采用 1–10 分制，并作为机器学习模型的因变量 Y。

同时，利用 Mask2Former 模型对 2000 份街景图像进行语义分割，提取 60+ 街景语义分割要素占比。随后，将这些分割要素归纳合并为 15 类客观街景指标，并作为模型的自变量 X。

在模型构建阶段，本项目对随机森林、XGBoost、LightGBM 和 Gradient Boosting 四类机器学习模型进行对比。结果显示，XGBoost 模型的 R² 表现最佳。因此，进一步对 XGBoost 模型进行参数调优，并利用调优后的模型对杭州市主城区约 2.8 万个街景点进行六维主观感知推广预测。

最后，将预测结果导入 ArcGIS Pro，分别按照 100m、150m 和 200m 间距构建渔网，开展空间冷热点分析，得到杭州市主城区街景主观感知的空间分布格局。

## 2. 研究区域

研究区域包括杭州市主城区中的以下区域：

- 滨江区
- 上城区
- 拱墅区
- 西湖区

## 3. 因变量 Y：六维主观感知得分

| 中文名称 | 含义 | 评分范围 |
|---|---|---|
| 安全 | 街景环境给人的安全感 | 1–10 |
| 活力 | 街道空间中的人气、活动性与生活气息 | 1–10 |
| 富裕 | 街景环境体现出的经济水平和空间品质 | 1–10 |
| 美丽 | 街景环境的景观美感和视觉舒适度 | 1–10 |
| 无聊 | 街景环境的单调性和缺乏吸引力程度 | 1–10 |
| 压抑 | 街景环境带来的空间压迫感和不舒适感 | 1–10 |

## 5. 模型方法

本项目对以下四类机器学习模型进行对比：

- 随机森林
- XGBoost
- LightGBM
- Gradient Boosting

模型评价指标主要包括：

- R²
- RMSE
- MAE

模型对比结果显示，XGBoost 模型整体表现最佳，因此选择 XGBoost 作为后续杭州市主城区推广预测模型。
