# 变量说明

## 1. 因变量 Y

因变量 Y 为六维主观感知评分，由专家训练后的大语言模型对 2000 份街景图像进行评分得到。

| 字段名称 | 含义 | 评分范围 |
|---|---|---|
| 安全 | 街景环境的安全感 | 1–10 |
| 活力 | 街道空间的人气和活动性 | 1–10 |
| 富裕 | 街景环境体现出的经济水平和空间品质 | 1–10 |
| 美丽 | 街景环境的景观美感 | 1–10 |
| 无聊 | 街景环境的单调性和缺乏吸引力程度 | 1–10 |
| 压抑 | 街景环境带来的压迫感和不舒适感 | 1–10 |

## 2. 自变量 X

自变量 X 为 15 类客观街景指标，由 Mask2Former 语义分割得到的 60+ 要素归并形成。

| 字段名称 | 指标含义 |
|---|---|
| N01_绿视率 | 街景图像中植被要素占比 |
| N02_水体 | 街景图像中水面、水体要素占比 |
| N03_天空 | 街景图像中天空要素占比 |
| N04_自然地表 | 街景图像中山地、沙地、自然地面等要素占比 |
| B01_建筑与墙体 | 建筑、墙体等空间界面要素占比 |
| B02_障碍与桥隧 | 护栏、围挡、障碍墙、桥梁、隧道等要素占比 |
| T01_机动车空间 | 道路、机动车道、停车空间等机动车通行空间占比 |
| T02_机动车数量 | 汽车、公交车、房车、拖车等机动车相关要素占比 |
| T03_静态慢行设施 | 人行道、自行车道、斑马线等慢行空间设施占比 |
| T04_动态慢行参与者 | 行人、骑行者、摩托车手等慢行参与者占比 |
| T05_交通控制设施 | 交通标志、交通信号灯、车道标线等交通控制设施占比 |
| U01_休憩与自行车设施 | 长椅、自行车架等街道休憩与停放设施占比 |
| U02_安全与照明设施 | 路灯、闭路电视摄像头、消防栓等安全照明设施占比 |
| U03_市政与便民设施 | 邮箱、人孔、电话亭、公用电杆等市政便民设施占比 |
| U04_界面信息杂乱度 | 横幅、广告牌、垃圾桶、标识等街道界面杂乱信息占比 |
