# Mask2Former 语义分割说明

本研究利用 Mask2Former 模型对街景图像进行语义分割，提取街景图像中的 60+ 类语义分割要素占比。

由于 Mask2Former 模型配置、原始街景图像和完整推理环境涉及较大的模型文件、数据体量以及环境依赖，本仓库暂不公开 Mask2Former 原始推理代码和完整环境配置。

本仓库主要公开以下内容：

1. Mask2Former 分割结果后的字段说明；
2. 60+ 语义分割要素归并为 15 类客观街景指标的规则；
3. 基于 15 类指标的机器学习建模代码；
4. XGBoost 参数调优与杭州市域推广预测代码；
5. SHAP 模型解释和 ArcGIS Pro 空间冷热点分析流程。

本研究中 Mask2Former 输出的 60+ 类语义要素主要包括：

- 天空
- 植被
- 水体
- 道路
- 建筑
- 墙体
- 护栏
- 自行车道
- 人行区
- 斑马线
- 停车场
- 交通标志
- 交通信号灯
- 路灯
- 广告牌
- 长椅
- 自行车架
- 垃圾桶
- 行人
- 自行车
- 公交车
- 汽车
- 摩托车
- 其他车辆

这些分割要素进一步归并为 15 类客观街景指标，用于后续机器学习建模。
